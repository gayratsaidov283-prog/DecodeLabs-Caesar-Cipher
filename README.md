# Caesar Cipher Encryption & Decryption

Cyber Security Internship — Project 2  
Decode Labs | October 2026

## Overview

A Python-based Caesar Cipher encryption and decryption tool
developed as part of the Decode Labs Cyber Security Internship.

The program encrypts text using a user-defined shift key and
decrypts the encrypted text back to its original form.

## Features

- Caesar Cipher encryption
- Caesar Cipher decryption
- User-defined shift key (1-25)
- Uppercase and lowercase support
- Preserves spaces, numbers, and special characters
- Alphabet wraparound using modulo 26
- Automatic encryption/decryption verification
- Automated unit tests

## Technologies

- Python 3
- unittest
- Git
- GitHub
